Privacy Policy – KurtYaz Uploads

Last updated: October 18, 2026

What this app is

KurtYaz Uploads is a private tool operated by Kurt Yazici (kurt@crushvertise.com). It is used only by Kurt to upload and schedule videos on his own YouTube channel. It is not offered to other users.

Data accessed

With the account owner's permission (Google OAuth), the app uses the YouTube Data API to read basic channel information and to upload videos, set video metadata (title, description, tags, category, scheduled publish time) and set thumbnails on Kurt's own channel. It does not collect, request or process data from any other person.

Storage

The OAuth access and refresh tokens are stored locally on Kurt's own computers, in files readable only by his user account. No Google user data is stored on any server or database operated by this app.

Sharing

The app does not sell, share, transfer or disclose any data to third parties, and does not use Google user data for advertising. Video files and metadata are sent only to YouTube, at Kurt's direction.

YouTube and Google

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See also the YouTube API Services Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the locally stored token files also removes the app's access.
