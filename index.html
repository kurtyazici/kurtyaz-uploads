KurtYaz Uploads

KurtYaz Uploads is a private tool used only by Kurt Yazici to upload and schedule videos on his own YouTube channel, Kurt Yaz (@kurtyaz).

It uses the YouTube Data API to upload video files, set titles, descriptions, tags, thumbnails and scheduled publish times on that one channel. It is not offered to the public and does not access anyone else's account or data.
